Push `.md` files into `content/` on `main` to publish via GitHub Pages.

- `content/index.md` — home page
- `content/<folder>/<note>.md` — notes (folders appear automatically in Explorer, Search, Backlinks, and Graph)
- Supports `[[Wikilinks]]`, `$math$`, `$$display math$$`, images, code blocks, and YAML frontmatter (`title`, `order`, `tags`, `draft`)
